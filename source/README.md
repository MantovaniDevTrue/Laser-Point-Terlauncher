# Source

This folder contains the Laser Pointer-specific source files and assets from version 1.0.

## Structure

- `Content/` — item, projectile, buff and global behavior
- `Core/` — targeting, immunity, state and visual logic
- `Localization/` — English and Portuguese localization
- `Textures/` — mod sprites
- `ContentOrder.json` — content registration order
- `main.js` — ExMod entry point
- `Settings.json` — package metadata

The release package also embeds the ExMod/TLPro framework under `TL/`. That framework is not duplicated here because this folder is intended to show the code specific to Laser Pointer.

The downloadable `Laser Pointer.tl` remains the complete ready-to-import package.
